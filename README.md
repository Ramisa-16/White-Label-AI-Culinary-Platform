- AI-powered recipe variations (branded)
- Analytics dashboard for chefs
- White-label customisation per client
- Content and monetisation control

## 🚀 Getting Started
```bash
git clone https://github.com/Ramisa-16/White-Label-AI-Culinary-Platform.git
cd White-Label-AI-Culinary-Platform
pip install -r requirements.txt && npm install
python manage.py runserver
```
